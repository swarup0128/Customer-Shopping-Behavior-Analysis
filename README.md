# Customer-Shopping-Behavior-Analysis
An end-to-end data  analysis of customer shopping data using Python, SQL, and Power BI to explore purchasing patterns, evaluate customer behavior, and uncover actionable insights that support data-driven business decisions.
**Project Name:** Customer Shopping Behavior Analysis  
**Repository Name:** customer-shopping-behavior-analysis  
**Author:** Swarup Dhore

### Project Overview
This is an end-to-end Data Analytics project focused on understanding customer shopping behavior and identifying meaningful patterns from purchase data.

The project involves:
- Loading and exploring the dataset using Python.
- Performing Exploratory Data Analysis (EDA).
- Cleaning and preprocessing data using Pandas.
- Connecting Python with PostgreSQL and loading the cleaned dataset.
- Writing SQL queries to investigate business questions and customer purchasing patterns.
- Developing an interactive Power BI dashboard to visualize key findings.
- Preparing a detailed project report documenting the complete workflow and results.

### Project Details
Use the following verified information:
- Dataset contains 3,900 customer purchase records and 18 columns.
- Missing review ratings were handled using the median rating of the corresponding product category.
- Feature engineering included creating customer age groups and purchase-frequency features.
- PostgreSQL was used for database integration and SQL analysis.
- Ten SQL business questions were explored.
- Power BI was used to create an interactive dashboard featuring key performance indicators, customer analysis, product performance and purchasing trends.
