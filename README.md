# Customer-Shopping-Behavior-Analysis
An end-to-end data  analysis of customer shopping data using Python, SQL, and Power BI to explore purchasing patterns, evaluate customer behavior, and uncover actionable insights that support data-driven business decisions.

Project Name: Customer Shopping Behavior Analysis
Repository Name: customer-shopping-behavior-analysis
Author: Swarup Dhore

## Project Overview
This project analyzes customer purchase data to understand spending habits, product performance, discount usage, customer segments, and subscription patterns.

## Dataset

- **Records:** 3,900 customer purchases
- **Columns:** 18
- **Missing Values:** 37 review ratings

## Tools & Technologies

- **Python & Pandas:** Data cleaning, preprocessing and Exploratory Data Analysis (EDA).
- **PostgreSQL & SQL:** Database integration and business analysis.
- **Power BI:** Interactive dashboard development.
- **DAX & Power Query:** Data transformation and KPI calculations.

## Project Workflow

1. **Data Exploration:** Loaded the dataset into Python and examined its structure, distributions and data quality.
2. **Data Cleaning:** Handled missing review ratings, standardized column names and created features such as `age_group` and `purchase_frequency_days`.
3. **SQL Analysis:** Loaded the cleaned data into PostgreSQL and answered 10 business questions related to revenue, customer segmentation, discounts, products and subscriptions.
4. **Dashboard Development:** Built an interactive Power BI dashboard to visualize key metrics and customer purchasing trends.

## Key Business Questions

- How does revenue vary across customer demographics?
- Which products receive the highest ratings?
- Do discounts influence customer purchasing behavior?
- How do subscribers and non-subscribers differ?
- Which customer segments contribute to purchasing activity?
- What is the relationship between repeat purchases and subscriptions?
